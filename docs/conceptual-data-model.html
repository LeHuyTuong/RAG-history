Conceptual Data Model

Hệ thống Lịch Sử Việt Nam — RAG Chatbot  |  Chỉ thể hiện khái niệm, không phụ thuộc DB cụ thể

📄 Nội dung & Tài liệu
Post (Bài viết)
  • id
  • title, slug
  • summary, content
  • thumbnailUrl
  • status (DRAFT/PUBLISHED)
  • publishedAt
  • → Admin (tác giả)
  • → Event (liên quan)
Source (Tài liệu)
  • id
  • title, sourceType
  • sourceUrl, filePath
  • author, publicationYear
  • reliabilityLevel
  • ↔ Tag (gắn nhãn)
  • → Qdrant (chunks)
Tag (Nhãn)
  • id
  • name (unique)
  • slug (unique)
  • description
  • ↔ Source (M:N)
🏛️ Thực thể Lịch sử
Period (Thời kỳ)
  • id
  • name (unique), slug
  • startYear, endYear
  • description
  • → Event (1:N)
Event (Sự kiện)
  • id
  • name, slug
  • description
  • startYear, endYear
  • certaintyLevel
  • ← Period (thuộc)
  • ↔ Person qua Participation
  • ↔ Location (M:N)
Person (Nhân vật)
  • id
  • name, slug, alias
  • birthDate, deathDate
  • biography
  • ↔ Event qua Participation
Location (Địa điểm)
  • id
  • name, slug
  • locationType
  • latitude, longitude
  • description
  • ↔ Event (M:N)
Participation
  • id
  • role, note
  • confidence
  • → Event
  • → Person
👤 Người dùng & Xác thực
Admin
  • id
  • username, email
  • passwordHash, fullName
  • status
  • → Post (1:N)
  • → RefreshToken (1:N)
Member (Thành viên)
  • id
  • username, email
  • passwordHash, fullName
  • status (ACTIVE/BANNED…)
  • → Engagement (1:N)
  • → RefreshToken (1:N)
RefreshToken
  • id
  • tokenHash, expiresAt
  • revoked
  • deviceInfo, ipAddress
  • → Member (hoặc)
  • → Admin
💬 Tương tác xã hội
Engagement (Tương tác)
  • id
  • engagementType (LIKE/COMMENT/RATE)
  • commentContent, commentStatus
  • ratingValue
  • → Member
  • → Engagement (parent, self-ref)
  • → Post (chưa implement)
🤖 RAG Pipeline (Qdrant Cloud — ngoài MySQL)
Chunk (Vector Point)
  • qdrantPointId (UUID5)
  • chunkText, chunkIndex
  • pageNumber
  • vector[768] (Gemini Embedding)
  • sourceId → Source
  • tagIds[] → Tag
  • articleId, documentId
Chat Session (stateless)
  • Không lưu DB
  • question → embed → Qdrant
  • topK chunks → Gemma 4
  • answer + citations
  • SSE stream

Lưu ý thiết kế:
  • Participation là "associative entity" giữa Person và Event — cho phép ghi thêm thuộc tính (role: vua/tướng/…, confidence: chắc chắn/nghi ngờ)
  • Engagement chưa có FK đến Post trong JPA — cần bổ sung để biết tương tác thuộc bài nào
  • Chunk sống trong Qdrant Cloud (không phải MySQL) — được liên kết với MySQL qua sourceId (denormalized trong payload)
  • Chat session stateless — không lưu lịch sử chat vào DB (có thể thêm sau nếu cần)
  • D003, D007 thiếu trong dataset — extraction benchmark fail với 2 PDF lớn ~250MB
